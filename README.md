# Protopiaos

Build out a clean, professional OS make sure the repo has a description a README and a full working react frontend. This needa to be adoptable by Windows users so it can't look too much like a nerd workstation dashboard it needs to be more familiar. One of the biggest fears for Windows users abandoning windows is that they would not be able to use applications like Windows office provides or that they might lose their files or their ability to manipulate their computer at all so we need to meet the user where they are and make the UX as familiar as possible for the windows user
